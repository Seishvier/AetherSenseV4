Tentang AetherSense

Real-Time Weather & Air Quality Intelligence Platform

AetherSense adalah aplikasi web sepenuhnya client-side yang menyediakan data cuaca dan kualitas udara real-time untuk kota manapun di dunia, dilengkapi rekomendasi cerdas untuk kesehatan, pertanian, dan aktivitas outdoor.

Platform ini tidak membutuhkan database, API key, maupun infrastruktur backend — ideal untuk deployment cepat di GitHub Pages atau layanan static hosting lainnya.

USP & Market Fit

  • Eco-tourism — Saran waktu optimal berkunjung berdasarkan kenyamanan cuaca & kualitas udara.
  • Precision Agriculture — Rekomendasi irigasi, tanam, dan perlindungan tanaman.
  • Public Health — Dukungan kesadaran dan pengambilan keputusan terkait paparan polusi udara.

Tech Stack

HTML5 CSS3 (Glassmorphism) Vanilla JavaScript Open-Meteo API Font Awesome 6 Google Fonts
