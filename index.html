    The project

    About AetherSense

    Unique selling point

    Most weather apps stop at the forecast. AetherSense converts free environmental data into three decision layers — personal health, agricultural action, and outdoor planning — inside one elegant interface. The agricultural engine is driven by universal weather parameters (humidity, wind, temperature, rainfall probability, UV), so its insights apply to farms in any climate. No proprietary sensors, no API key, no backend.

    Market fit

    • Eco-tourism — optimal visit windows from comfort + air quality.
    • Precision agriculture — irrigation, planting, spraying, and frost alerts.
    • Public health — pollution exposure awareness for schools and offices.
    • Smallholder advisory — globally portable field guidance without sensors.

    Tech stack

    • HTML5, CSS3 (custom properties, backdrop-filter), ES6+ JavaScript
    • Inter + Playfair Display — Google Fonts
    • Font Awesome 6 icons
    • Zero build step, zero runtime dependencies

    Data sources

    • Open-Meteo Geocoding API — city lookup
    • Open-Meteo Forecast API — current, hourly, daily, UV
    • Open-Meteo Air Quality API — European AQI, PM2.5, PM10, gases
    • All endpoints free and keyless
