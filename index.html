About AetherSense

What it is

AetherSense is a fully client-side environmental intelligence platform. It combines real-time weather, air-quality data and rule-based reasoning to answer a practical question: what should I do right now, given the conditions here?

Unique selling proposition

  • Three insight domains — health, agriculture, outdoor activity — in one interface.
  • Zero backend, zero database, zero API keys: deployable to any static host in minutes.
  • Adaptive glassmorphism UI that visually reflects the searched location's weather.

Market fit

  • Eco-tourism — optimal visit windows using comfort + air quality.
  • Precision agriculture — irrigation, spraying, planting and frost guidance.
  • Public health & urban planning — pollution exposure awareness.

Tech stack

  • HTML5 semantic markup · CSS3 variables, backdrop-filter, grid
  • ES6+ vanilla JavaScript — no frameworks, no build step
  • Inter + Playfair Display (Google Fonts) · Font Awesome 6

Data sources

  • Open-Meteo Geocoding API — city → coordinates
  • Open-Meteo Forecast API — current, hourly, 7-day
  • Open-Meteo Air-Quality API — European AQI, PM2.5, PM10, O₃, NO₂, SO₂, CO
  • All free for non-commercial use, no key required

Deployment

  • Three files: index.html, styles.css, script.js
  • Push to a GitHub repository root
  • Settings → Pages → Deploy from branch → main / root
  • Live at https://<username>.github.io/<repo>/
